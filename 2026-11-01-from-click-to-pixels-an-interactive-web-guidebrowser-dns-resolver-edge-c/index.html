04 / USE THIS MENTAL MODEL

Ask which part is actually slow.

Before a response arrives

Look at name resolution, connection setup, server or edge time, and transfer. Connection reuse, protocol versions, and cache policy change that work.

After bytes arrive

Look at resource dependencies and main-thread work. A quick first byte can coexist with a late image, blocking script, or expensive layout.

On a repeat visit

Inspect individual resources and their response headers. Some can be reused, others validated, and others fetched again. A browser reload is not identical to a normal navigation.

When reading a waterfall

Treat timing as measured evidence, not a universal constant. This guide teaches relationships; it does not predict a site's loading time.
